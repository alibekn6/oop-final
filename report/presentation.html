Four Design Patterns

Pattern Class / Files Role in the system
Singleton storage/DataStore.java Single global state holder. Thread-safe getInstance(). Serializes the entire object graph to data.ser.
Factory factory/UserFactory.java createUser(UserType, ...) dispatches by enum to the correct User subclass. Hides constructor variance.
Decorator models/ResearcherDecorator.java Wraps any User to grant the Researcher role at runtime without modifying the wrapped class. Used by Manager.makeResearcher.
Strategy comparators/*.java (3) DateComparator, CitationsComparator, PaperLengthComparator — interchangeable algorithms passed to printPapers(Comparator).

Each pattern closes a specific spec line

  • Singleton → "properly working serialization (think about Data Storage and some pattern)"
  • Decorator → "Researcher created using Decorator pattern? Figure it out"
  • Strategy → "PrintPapers(Comparator c) ... by date, citations, or length"

Custom Exceptions

All four are checked (extends Exception) and model business-rule violations the caller must handle.

Exception Thrown when Spec citation
CreditLimitException Student registers for a course that would exceed 21 total credits "Students can't have more than 21 credits"
MaxFailedReachedException Student has accumulated 3 failed courses; cannot register or fail more "Students can't fail more than 3 times"
LowHIndexException Supervisor candidate has h-index < 3 "If a person whose h-index < 3 is assigned as a supervisor, a custom exception must be thrown"
NotAResearcherException Non-researcher tries to join a ResearchProject "If someone who is not a Researcher tries to join the ResearchProject, custom Exception must be thrown"

All four are demonstrated in UniversityDemo and reachable from the CLI flows.

H-index calculation

Largest h such that h papers each have ≥ h citations. Implementation in ResearcherSupport.

static double hIndex(List<ResearchPaper> p) {
    List<ResearchPaper> s = new ArrayList<>(p);
    s.sort((a, b) -> Integer.compare(
                       b.getCitations(),
                       a.getCitations()));
    int h = 0;
    for (int i = 0; i < s.size(); i++) {
        if (s.get(i).getCitations() >= i + 1)
            h = i + 1;
        else break;
    }
    return h;
}

Persistence & Demo Data

Persistence

  • Java object serialization (ObjectOutputStream)
  • Whole DataStore graph → data.ser
  • All models implement Serializable
  • Triggered by:
    • JVM shutdown hook (covers Ctrl-C, terminal close)
    • End of every user session (logout)
  • Load on startup restores the entire object graph with all back-references intact
